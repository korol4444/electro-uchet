# ЭлектроУчёт — интеграция Home Assistant (HACS)

Интеграция для ежедневного учёта электроэнергии по накопительному датчику Home Assistant. Тариф по умолчанию — **6 ₽/кВт⋅ч**.

## Возможности
- Выбор накопительного датчика через интерфейс Home Assistant.
- Однотарифный расчёт стоимости.
- Расход и стоимость за сегодня и текущий месяц.
- История по дням (до 365 дней) и агрегаты по месяцам (до 13 месяцев) в атрибутах сенсоров.
- Сравнение текущего месяца с предыдущим за такое же количество календарных дней.
- Изменение тарифа в настройках интеграции.
- Локальное хранение истории в Home Assistant.

## Установка через HACS
1. Убедитесь, что репозиторий доступен HACS (для стандартной установки используйте публичный репозиторий).
2. Откройте **HACS → Интеграции → ⋮ → Пользовательские репозитории**.
3. Добавьте `https://github.com/korol4444/electro-uchet`, категория — **Integration**.
4. Найдите **ЭлектроУчёт**, установите и перезапустите Home Assistant.
5. Откройте **Настройки → Устройства и службы → Добавить интеграцию → ЭлектроУчёт**.
6. Выберите накопительный датчик, например `sensor.energy_total`, и задайте тариф `6`.

## Установка вручную
Скопируйте папку `custom_components/electro_uchet` в `/config/custom_components/electro_uchet`, затем перезапустите Home Assistant.

## Создаваемые сущности
- `sensor.electro_uchet_today_energy` — расход за сегодня, kWh.
- `sensor.electro_uchet_today_cost` — стоимость за сегодня, ₽.
- `sensor.electro_uchet_month_energy` — расход за месяц, kWh.
- `sensor.electro_uchet_month_cost` — стоимость за месяц, ₽.

У сенсоров доступны атрибуты `история_по_дням`, `история_по_месяцам`, тариф, последнее показание и время обновления.

## Графики
Добавьте сущности в стандартные карточки **История** или **Статистика** Lovelace. Исторические массивы также доступны в атрибутах сенсоров; их можно визуализировать через Markdown/Template или ApexCharts.

## Важные ограничения
- История начинается с установки интеграции; старые данные Recorder не импортируются.
- Разница накопительного показания относится к текущим местным суткам Home Assistant. Для точного распределения по дням исходный датчик должен обновляться регулярно, особенно около полуночи.
- Уменьшение показания трактуется как сброс/замена счётчика: отрицательное потребление не записывается.
- Скачок более 1000 кВт⋅ч между обновлениями пропускается как защита от некорректных данных.
- При изменении тарифа стоимость пересчитывается для всей сохранённой дневной истории.

Это интеграция Home Assistant, а не отдельный сервер или Supervisor add-on.
